# Сперанский AI Mini App

Лёгкий клиент на HTML, CSS и JavaScript без сборки. Основные функции интерфейса — текстовые чаты, прикрепление фото и выбор модели. Секреты и ключи API не должны храниться в этом репозитории или в клиентском коде.

## Структура клиента

Клиент собран из обычных скриптов без сборщика; порядок загрузки задан в `index.html`:

- `js/i18n.js` — словари интерфейса, форматирование plural/date/number, сохранение и восстановление языка;
- `js/config.js` — константы, данные Telegram, селектор `$`;
- `js/api.js` — инициализация Telegram и сетевой слой;
- `js/logos.js` — логотипы провайдеров;
- `js/brand.js` — знак «Сперанский AI» (глиф, заготовки `.logo[data-logo]`);
- `js/render.js` — markdown и формулы, кнопка «Копировать» у блоков кода;
- `js/ui.js` — время в списке чатов, прокрутка, свайп-закрытие шторок, theme-color;
- `js/icons.js` — SVG-иконки и хаптики;
- `js/models.js`, `js/models-list.js` — статусы, поиск и список моделей;
- `app.js` — состояние, чаты, отправка сообщений, шторки и запуск.

Знак приложения живёт в двух местах: инлайном в стартовом экране `index.html`
(чтобы рисовался до загрузки скриптов и без сети) и в `js/brand.js` для всех
остальных мест. Совпадение контуров проверяет тест. `logo.svg` — тот же знак
для иконки вкладки / apple-touch-icon, `logo-180.png` — растровая версия.

Версия кэша задаётся в трёх местах и должна совпадать: `?v=` в `index.html`, `window.__NEED_APP_V` в `index.html` и `window.__APP_V` в `app.js`. Тесты проверяют совпадение.

## Интерфейс: что где

- **Шапка** — название чата (тап открывает меню чата) и пилюля модели
  (логотип провайдера + короткое имя). Пока модель отвечает, под шапкой
  бежит полоса, а рядом с пилюлей написано «печатает…».
- **Лента** — автоскролл вниз только когда ты и так у низа: если читаешь
  историю, стрим её не дёргает, а на кнопке «вниз» загорается точка.
  Историю при открытии чата показываем без «дождя» анимаций.
- **Композер** — кнопка отправки всегда на месте (при пустом поле — приглушена),
  при остатке лимита ≤ 5 над полем появляется предупреждение с правильной
  формой слова («осталось 3 запроса»), фото можно вставить из буфера или
  перетащить; без текста к фото отправка подсказывает, что нужен вопрос.
- **Список чатов** — группы «Закреплённые / Сегодня / Вчера / На этой неделе /
  Раньше» и человеческое время вместо машинной даты, поиск по названию и модели.
- **Меню чата** — только рабочие действия: переименовать (тот же
  `PUT /api/chats/:id`, что и смена модели), закрепить, поделиться, фото из
  чата, поиск, удалить.
- **Модели** — поиск по всем категориям, скелетон до загрузки списка, галочка
  у выбранной модели.
- **Шторки** — закрываются кликом по фону, жестом вниз (боковое меню — влево)
  за ручку и клавишей Esc; на десктопе свайп отключён.
- **Мелочи** — тосты вместо плашек в потоке, галочка «Скопировано» прямо в
  кнопке ответа, копирование блоков кода, 4 плитки быстрых действий на пустом
  экране, `theme-color` под тему, хаптики и `prefers-reduced-motion` (в том
  числе на отрисовку знака — при отключённой анимации буква сразу видна).

## Язык интерфейса

При первом запуске интерфейс открывается на английском. В настройках можно
выбрать English, Русский, Español, Português, Français, Deutsch, हिन्दी, 中文
или العربية; выбор сохраняется вместе с остальными настройками и восстанавливается
до запуска приложения. Все статические подписи и динамически создаваемые
элементы используют общий словарь `js/i18n.js`; даты, числа и формы слов
форматируются для выбранной локали. Для арабского включается направление RTL.

## Ответы сервера, которые клиент показывает по-человечески

`initData` уходит с каждым запросом. Разбор ошибок — `apiError()` в `js/api.js`:

- `403` + `code: "subscribe"` — экран «Нужна подписка» с текстом из `message`/`error` и кнопкой «Подписаться» (если есть `channel_url`; `t.me` открывается через `Telegram.WebApp.openTelegramLink`);
- `503` + `code: "maintenance"` — экран техработ, чат не открывается, есть «Повторить»; тихого обхода через `/api/models` и `/api/chats` нет;
- `401` — локализованное сообщение о неподтверждённой сессии;
- `429` + `error: "quota"`, `503` + `error: "busy"` — текст `message` от сервера, если он есть, иначе локализованная подсказка из словаря;
- `200` + `filtered: true` — показывается `reply`, счётчик квоты не уменьшается;
- `409` + `code: "chat_limit"` при создании чата — текст `error`;
- `free`, `donate_url`, `donate_note` из `/api/quota` или `boot.policy` — строка «Бесплатно» / «Поддержать · бесплатно» в меню чатов.

## Клавиатура

Пока `#input` в фокусе, над лентой и пустым экраном лежит прозрачный слой `#kb-shield` (под шапкой, композером и шторками). Первое касание по нему убирает фокус с поля и прячет слой. Если под пальцем кнопка, ссылка или поле, клавиатура остаётся открытой, а тап передаётся этому элементу.

## Голосовой ввод и озвучивание

Встроенные голосовые функции Mini App отключены: приложение не записывает аудио, не распознаёт речь, не отправляет запросы на распознавание и не озвучивает ответы. Оно не запрашивает разрешение на микрофон. На телефоне по-прежнему можно использовать системную диктовку клавиатуры, если её предоставляет ОС.

Если ответ сервера для устаревшего голосового клиента содержит `410` и `error: "voice_disabled"`, клиент показывает короткое сообщение: «Голосовой ввод отключён — напишите запрос текстом».

## Проверки

Запустить проверки встроенным тест-раннером Node.js:

```sh
node --test tests/mini-app.test.cjs tests/ui-polish.test.cjs tests/i18n.test.cjs
node --check js/i18n.js && node --check js/config.js && node --check js/api.js && node --check js/logos.js && node --check js/brand.js && node --check js/render.js && node --check js/ui.js && node --check js/icons.js && node --check js/models.js && node --check js/models-list.js && node --check app.js
```

Они проверяют английский язык при первом запуске, восстановление выбранной локали, полноту переводов для всех девяти языков, отсутствие встроенного аудиозахвата/распознавания и TTS, доступность обычной отправки текста, обработку `voice_disabled`, разбор ошибок сервера, слой клавиатуры, отсутствие скрипта Cloudflare, совпадение контуров знака в `index.html` и `js/brand.js`, видимость знака при `prefers-reduced-motion`, контекст шапки, группировку списка чатов, поведение прокрутки при чтении истории, отсутствие мёртвых пунктов «скоро», нетронутый контракт API бота (`/api/boot`, `/api/chat` и остальные), поиск по моделям, свайп-закрытие шторок, предупреждение о лимите и копирование блоков кода.

Есть ещё живой прогон клиента в jsdom — он ловит то, чего в регулярках не видно: запуск приложения, отправку сообщения со стримом, шторки, смену языка и его восстановление, настройки, переименование чата и «отказные» экраны сервера (подписка, техработы, лимит, 401, отсутствие `initData`). Он необязательный, потому что требует jsdom:

```sh
npm i --no-save --prefix /tmp/sp-dom jsdom
NODE_PATH=/tmp/sp-dom/node_modules node tests/dom-smoke.cjs
```
