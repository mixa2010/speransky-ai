# Сперанский AI Mini App

Лёгкий клиент на HTML, CSS и JavaScript без сборки. Основные функции интерфейса — текстовые чаты, прикрепление фото и выбор модели. Секреты и ключи API не должны храниться в этом репозитории или в клиентском коде.

## Голосовой ввод и озвучивание

Встроенные голосовые функции Mini App отключены: приложение не записывает аудио, не распознаёт речь, не отправляет запросы на распознавание и не озвучивает ответы. Оно не запрашивает разрешение на микрофон. На телефоне по-прежнему можно использовать системную диктовку клавиатуры, если её предоставляет ОС.

Если ответ сервера для устаревшего голосового клиента содержит `410` и `error: "voice_disabled"`, клиент показывает короткое сообщение: «Голосовой ввод отключён — напишите запрос текстом».

## Проверки

Запустить проверки встроенным тест-раннером Node.js:

```sh
node --test tests/mini-app.test.cjs
node --check app.js
```

Они проверяют отсутствие встроенного аудиозахвата/распознавания и TTS, доступность обычной отправки текста, обработку `voice_disabled` и параметры анимации стартового логотипа.
